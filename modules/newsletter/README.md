# 📰 뉴스레터 (Newsletter)

## 목적
한전 청구서사업·전기·에너지·지자체 관련 최신 기사를 실시간으로 수집하여
경영진 보고용 뉴스 스크랩을 작성·발송하고, 지식베이스로 누적 관리한다.

## 핵심 기능
- **실시간 뉴스 연동**(`fetchLiveNews`): 구글 뉴스 RSS / 자체 서버 / 아카이브 JSON 3방식
- **날짜 자동 최신화**: `new Date()` 기반 당일 날짜 자동 표시
- **카테고리 필터**: [전체] [에너지 관련 사업] [지자체 뉴스] 즉시 필터
- **탭**: 오늘 기사 / 지난 기사(아카이브) / 발송 이력
- **이메일 발송**(EmailJS) + HTML 복사 + 지식베이스(KB) 내보내기
- **CORS 우회 가이드**: 코드 주석에 프록시/서버 스크래핑 3방식 상세 기술

## 데이터 출처 (Google Drive: AX 폴더)
| 데이터 | 파일 |
|--------|------|
| 뉴스 아카이브 | `news_archive.json` (07-08 신규) |
| 수집 스크립트 | `news_collector.js` (Node, 스케줄 실행용) |

## 사용법
`index.html`을 브라우저로 열면 뉴스레터 화면으로 진입.
실시간 연동은 로딩 시 자동 시도, 실패 시 기본 데이터로 폴백.
