# 📞 민원분석 (Complaint Analysis)

## 목적
콜센터 상담 통화(STT)와 VOC를 AI로 분석하여 민원 패턴·해결률·감정을 파악하고,
서비스 품질 개선과 예상 민원 선제 대응을 지원한다.

## 핵심 기능
- **분석 기간 컨트롤러**: 최근 3개월·6개월·월별 필터 (5월 데이터 누락 보정 안내 포함)
- **AI 분석 내역 요약**: 감정지수·주요키워드·해결난이도·자동분류율 카드형 그리드
- **민원 해결률 세분화**: 한전 이관 vs 자체 해결 이중 막대 그래프(비율 %)
- **개선 제안 & 우수 발화**: 탭 분리 + 상세 스크롤 박스
- **VOC 분석 / AI 예상 민원 / 인입 키워드**
